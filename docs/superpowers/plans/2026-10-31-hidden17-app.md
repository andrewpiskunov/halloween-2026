# Mini App: правила закрытых намерений для 17 игроков

Источник требований: `docs/design/gm-book/hidden-17.json`, книга `docs/prototypes/magic-fair-v2.html`, согласованный финал `finale-sheet.html`. Новые правила реализуются в серверном движке и интерфейсе, не только текстом.

## Общие ограничения
- Ровно 17 основных ролей из hidden-17; ведущий отдельно. Архив 30 сохраняется.
- Старый журнал событий воспроизводится без переписывания и потери имущества. Новая партия использует hidden17; существующую активную старую партию нельзя автоматически переводить или сбрасывать.
- Полный сценарий находится на сервере. Игроку только своя вводная, публичные правила, наблюдаемые события; никаких чужих целей, сторон, владельцев скрытых вещей или тайных способов в payload/bundle.
- Существующие способности, обмены, заявки ведущему и согласие остаются работоспособными.
- Не коммитить чужие изменения, реальные игровые данные или секреты. Изменения выполнять в текущей ветке codex/hidden17-app; не сбрасывать прежнюю работу.

## Task 1: Серверные правила и проекции (исполнитель)
Владение: только `apps/mini-app/packages/shared/**`. До реализации сообщить контроллеру контракт команд/типов/проекций; контроллер делает server/client.

Реализовать опциональный режим hidden17 (отдельный event для включения только setup; новый server его включает при пустом журнале; reset новой партии возвращает режим через event). Источник hidden17 JSON передаётся сервером в Content отдельным полем, не статическим импортом в shared runtime. Предоставить `enable` command для GM/setup, сервер вызовет при создании. Состав17 фиксирован. Осколок V у Лиры доступен с начала, IV+A лот II. Публичные фракции, старые алтари, lore с тайнами, clues и story в новой проекции санитизировать. Новый `PlayerView.hidden17` содержит безопасную собственную вводную и только доступные методы; `GameState.hidden17` полный новый игровой учёт. Выбор стороны/старые алтари заблокировать.

Изготовление: старый shop.craft в новом режиме означает заказ мастеру (без createdBy игрока). Личное производство Греты все4, Клёпы focus/ward, Ады cleanse, Вельды focus; клиент с материалами+платой банку+оговорённым гонораром автору явно соглашается, атомарная доставка и учёт createdBy. Собственные способности и Астрина копия сохраняют ограничения, скидка сначала к базе>=0, шипы затем +1. Три уникальных товара (shape-fixative, inspection-lens, herbal-incense), по1 заакт отдельно от способности, фиксированная цена/материалы, согласие на применение; полные эффекты по JSON. Уникальные не обычные изделия для целей и не сырьё ритуала/разборки.

Таверна: объявления с условиями, проверкой, наградой, сроком. Награда материальная резервируется (item reservedFor, свободные золото/ингредиенты учитываются во всех старых путях); услуга фиксируется как обязательство с согласием/ведущим, без автоматического чужого действия. open/accepted/completed/cancelled/expired. Один исполнитель. После принятия отмена по согласию обоих или GM. GM подтверждает сцену и выдаёт резерв атомарно, завершение без повторного вето автора. Слухи явно непроверенные. Реальные кости: согласие2игроков, ставка0или1 каждого, резерв, GM фиксирует два результата d6, ничья возврат; не счётчик обменов/способностей. Закрыть/вернуть резерв доски и не начатых костей передфиналом.

Ритуал: публичная надпись доступна всем; частные рецепты salt (Ада/Эльмар,1potion), sign (Вельда/Астра,1focus+имя контроллера+одна заранее выбранная команда), vessel (Грета,1potion) обучаемы через GM подтверждение. Подготовка до финала. GM ведёт5шагов. Любые3целых разныхчасти+2focus добровольно владельцами, владение сохраняется; до порошка отзыв бесплатен. Powder тратит2focus и открывает риск. Formula точная изJSON, один скрытый выбор на игрока; собственная/разрешённая/вкруге часть доступна соли. Withdraw раньше salt, невалидная из-заотзыва соль не тратится. Reveal только наблюдаемое. Отмена своего раскрытого вмешательства не возвращает компонент. Каждый1свойward блокирует1попытку; дубли не тратятся; нельзя блокировать отзыв. Эффекты одновременно. >=3погашенных уникальных частей destroyed; иначе после последнего выбора >=3целых соединённых awake иначеsleep. Активные контроллеры:0free,1ограниченная заранее записанная команда дорассвета,2+имёнfree; отсутствующий контроллер не считается. Сосуд1full/>1weak/нетпробужденияempty. Итог жизнь/свобода/сила отдельно, личныецели независимо. Посленачала запрет обычных обменов/крафта/способностей, разрешённые финальные команды остаются. Ведущий подтверждает публичноеA+B+C разныхвладельцев/осознанное предложениеСерафины/отречениеВельды; не требовать всеулики в однойсумке. Новый closing не использует фракционные очки.
