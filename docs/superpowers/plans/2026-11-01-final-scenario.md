# Итоговая редакция сценария — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Полностью согласовать сценарий для 17 ролей, серверные правила, приложение и книгу, затем объединить ветку одним коммитом в main.

**Architecture:** Сценарные JSON остаются источником текущей редакции, сервер исполняет правила и отдаёт ограниченные проекции. Маркер rulesVersion=2 отделяет новые партии от старых журналов. Генератор создаёт актуальные HTML и снимок.

**Tech Stack:** TypeScript, pnpm, Vitest, React, Playwright; Python-генератор книги.

**Spec:** docs/superpowers/specs/2026-11-01-final-scenario.md

## Global Constraints

- Ровно 17 базовых ролей и отдельный ведущий. Сив входит в базовые 17; дополнительные роли не участвуют.
- Русский язык. Сохраняются личные истории, две цели, обмены, уникальные способности и подсказки отыгрыша всех 17 ролей.
- Расследование — личная линия Корвина; доказательства убийства не открывают обряд и не являются условием пробуждения.
- Исходные DOCX/XLSX, архивные редакции, материалы печати и иные незакоммиченные файлы основного worktree не изменять.
- Новая редакция действует в новых/сброшенных партиях. Сохранённые партии не получают новые монеты, цены, подготовку обряда или защиты незаметно; старый журнал должен воспроизводиться. Маркер `hidden17.rulesVersion: 2` копируется из сценария только при создании новой редакции. Отсутствие маркера означает прежние механические правила. В README явно указать, что текущие тексты сценария обновлены; для продолжения старой партии нужна её прежняя сборка.
- Полная книга остаётся только на сервере. Игрок видит собственные знания и переданные документы, а чужие замыслы — только после предусмотренного раскрытия.
- Каждый коммит: автор и коммиттер Andrew Piskunov <45717261+andrewpiskunov@users.noreply.github.com>. Без Co-authored-by и упоминаний инструментов.

## Review Focus

- Старый журнал после перезапуска и новая игра после reset: разные цены/старт/ритуал, без повторной выдачи золота (Task 1).
- Неявка, отзыв допуска или отозванный вклад в последние пять минут: нет зависших резервов и преждевременного закрытия торговли (Task 1).
- Отменённая первая попытка и действующая вторая того же донора/осколка: групповая защита работает, двойной расход исключён (Task 1).
- Зритель, чужая сумка, непереданный документ: закрытые знания/состав не раскрываются через новые проекции/линзу (Task 1, Task 3).
- Несовместимые желания 17 героев: документы заранее называют предел помощи, полная/частичная оценка учитывает реальный результат, не обещание (Task 2).
