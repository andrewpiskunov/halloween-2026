# Непрерывная ярмарка и закрытый обряд

Согласовано в разговоре 1 ноября 2026; владелец поручил реализовать все изменения.

- Одна непрерывная ярмарка. Нет видимых актов и переходов между ними. Аукцион осколка IV с уликой A — отдельное событие ведущего. Обновить способности и пополнить мастерскую можно отдельно, по два раза за вечер: сохраняем прежний общий запас применений/материалов без границ актов. Временные эффекты действуют до обновления сил.
- Кровная привязка: знающий способ расходует Фокус и наполняет бутылёк собственной кровью; донор фиксируется автоматически. Бутылёк можно передать, при использовании власть получает донор. Заранее выбранных приказов нет: после пробуждения произносится одно выполнимое распоряжение до рассвета, ведущий определяет исполнение. Разные сохранившиеся доноры срывают все привязки, несколько бутылей одного донора не умножают приказ.
- Соль готовится из одного зелья. В любой момент ярмарки владелец своего свободного осколка с готовой солью запрашивает сцену. Ведущий объявляет её: соль тратится, открывается двухминутное окно. Автор может отказаться; любой присутствующий может потратить один талисман и спасти осколок. Тратится только первый талисман. Ведущий подтверждает разрушение после окна; автоматического уничтожения по таймеру нет. Предмет остаётся у владельца при спасении, при разрушении исчезает, номер попадает в необратимый список уничтоженных. Повторная попытка требует новой соли. До запуска сцены заявку можно отменить с возвратом резерва соли.
- Пять осколков: один/два уничтожены — остаются четыре/три; три уничтожены — пробуждение невозможно. Нет зависимости от трёх разных разрушителей.
- Походы оформляются обычной свободной закрытой заявкой ведущему, с местом и временем в тексте. Нет кнопки, раскрывающей тайное место. Каждый спутник подаёт/подтверждает свою заявку. Ведущий по существующей заявке фиксирует допуск и время прибытия; только эти герои входят в круг. При старте состав замораживается, позднего входа и передачи предметов внутрь нет.
- Публичный показ закрытой сцены: все видят ход и раскрытые эффекты, но сервер принимает действия только вошедших. Скрытые выборы и заявки зрителям не выдаются. Наблюдение не даёт персонажу знания обряда.
- Четыре этапа для игрока: сбор; пробуждение сердца и подготовленные вмешательства; раскрытие/ответы; последний выбор/исход. Внутренние шаги powder/choices остаются совместимыми с журналом.
- Внутри круга соль может действовать на чужую часть в круге; вне круга — только на собственную или с разрешения владельца. Каждый расходник используется один раз; ограничение «одно основное вмешательство на человека» снимается, чтобы подготовленные ресурсы работали последовательно и один герой мог погасить несколько частей. Защита в общем ответном окне — один талисман на человека; отдельные сцены до обряда независимы.
- Силовые и прочие свободные действия до замыкания круга разбирает ведущий через существующие заявки и передачу предмета по результату сцены. Новый обязательный бой на d6 не вводится: после обсуждения выбран закрытый круг, устраняющий позднее силовое вмешательство зрителей.
- Если обряда нет или он невозможен, ведущий может закончить вечер сном/гибелью сердца и перейти к эпилогам. Нет обязательного успешного воскрешения.
- Старые события, id предметов и сохранённые сделки не переписываются. Новая редакция включается отдельным событием до финала; уже начатый старый финал завершается по прежним правилам. Новые партии запускаются в новой редакции.
