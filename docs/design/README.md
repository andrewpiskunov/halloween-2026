## Сюжет и конфликт

Сердце дракона продают по частям. Три группы хотят пробудить дракона, подчинить его магию или разрушить сердце. У каждой группы по четыре персонажа. Ещё пять участников преследуют собственные интересы и выбирают желаемый исход до 60-й минуты.

У персонажа две личные цели и достижение за желаемый исход. Весёлая задача для отыгрыша не даёт очков. Нет выбывания: игрок продолжает торговать и общаться до финала.

## Ресурсы и обмены

- Каждый игрок начинает с 6 золотыми и 3 базовыми ингредиентами.
- Базовые ингредиенты: Пепел феникса, Лунная пыль и Роса междумирья.
- Обычная покупка ингредиента у ярмарки стоит 2 золотых; запасы ограничены.
- Четыре общих рецепта: очищающее зелье, защитный талисман, Фокус силы и камень облика.
- В игре восемь уникальных реликвий и пять различных осколков сердца.
- Реликвии нужны для целей и торговли; они не имеют скрытых способностей.
- Сделка выполняется только после согласия обеих сторон; до этого предложенные ресурсы зарезервированы.

## Способности

Одна активная способность за акт. Способности облегчают обычные действия, не делают роль единственным способом получить обязательный результат. Враждебные воздействия ограничены: кража одной доступной монеты или удорожание следующего изготовления на одну монету. Не более одной враждебной попытки по одному игроку за акт; защита может её остановить.

## Финал

Каждому ритуалу нужны три разных осколка, два Фокуса силы и шесть золотых от как минимум трёх участников. Всего осколков пять, поэтому одновременно завершить два ритуала нельзя. До фиксации финала вклад можно забрать. Если не готов ни один ритуал, сердце остаётся спящим; личные достижения всё равно учитываются.

## Квартира и мини-игры

| Зона | Назначение | Мини-игра |
| --- | --- | --- |
| Большая комната | Рынок, объявления, вклады в ритуалы | «Торг за лот»: закрытые ставки |
| Вторая комната | Мастерская, изготовление и услуги | «Рунный контур»: общий порядок рун по личным подсказкам |
| Кухня | Таверна, неформальные переговоры | «Дуэль блефа»: одновременный выбор знаков со ставкой |

Участники свободно перемещаются. Мини-игры необязательны и не заменяют обычную торговлю и изготовление.

## Время

| Минуты | Этап |
| --- | --- |
| 0–10 | Правила и знакомство с ролью |
| 10–35 | Первый акт |
| 35–60 | Второй акт, новый осколок на рынке |
| 60–85 | Третий акт, последний осколок |
| 85–100 | Фиксация действий и финал |
| 100–120 | Раскрытие ролей и обсуждение |

## Неявка

Приложение должно учитывать фактический состав. Редкие предметы отсутствующих персонажей переходят на открытый рынок, обычные стартовые ресурсы отсутствующих не добавляются в экономику. Контакты и распределение ресурсов пересчитываются. Ключевые действия доступны без конкретного владельца способности.

В HTML есть планировщик для 13–17 игроков. Меньший состав требует отдельной адаптации. Пробный прогон нужен и для полного состава.

## Данные

[game-data.json](game-data.json) — точный экспорт объекта `DATA` из `docs/prototypes/magic-fair.html` на момент импорта в репозиторий. Содержит 17 ролей с отыгрышем, 4 группы (включая независимых), 8 реликвий, 4 рецепта и 3 комнаты.

Это снимок для дальнейшей разработки, а не подключённый источник данных HTML. Прототип продолжает использовать встроенный объект. Пока автоматической сборки нет, изменения нужно синхронизировать вручную. Правила таймеров, обменов, мини-игр и макета приложения находятся также в тексте и JavaScript внутри HTML; одним JSON они не исчерпываются.

Расхождение с `game-data-v0.2.json` после этапа 5 Mini App: условия личных целей и тексты исходов в снимок не добавлены. Они лежат в коде приложения: условия в `apps/mini-app/packages/shared/src/goals.ts`, тексты исходов в `apps/mini-app/packages/shared/src/closing-texts.ts`. Тексты целей по-прежнему берутся из `role.goals` снимка. Если меняется формулировка цели в данных, условие в `goals.ts` надо проверить вручную.

Проверка выбранного сочетания: интерфейс «Гравюра» с портретами в плоской графике через фильтр, в цвете и в приглушённом варианте — [../prototypes/ui-engraving-check.html](../prototypes/ui-engraving-check.html).
