Надпись у могилы Сарна

Для размещения на игровом месте.

  1. Здесь покоится Сарн Пепельнокрылый. Вернуть дыхание можно лишь у его останков, когда закрывается столетний брод.
  2. Положите в гнёзда любые три целые части сердца. Можно больше. Владельцы делают это по своей воле.
  3. Разотрите два Фокуса силы в одну пыль и замкните ею круг вокруг частей.
  4. Один человек ведёт, остальные желающие повторяют: «Сарн, вернись к своему сердцу. Сердце, верни ему жизнь».
  5. После первого удара смотрите, что происходит с кругом. Прежде чем сомкнуть руки для последнего удара, каждый ещё может отвести свою часть.
Сарн, вернись к своему сердцу. Сердце, верни ему жизнь.

Порядок: гнёзда → пыль → формула → наблюдение → последнее решение. Всё проводится вместе с ведущим в момент закрытия брода.
