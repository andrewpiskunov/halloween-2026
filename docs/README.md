# Документация

## Актуальный задел

- [Требования](requirements.md) — формат вечера, предпочтения, что уже выбрано и что остаётся предложением.
- [Проект правил](design/README.md) — текущая версия «Ярмарки украденной магии».
- [Проект 0.2](design/magic-fair-v0.2.md) — игра на 12–30 человек: состав, финал, начало, бумажный комплект, приложение.
- [Спецификация Telegram Mini App](design/mini-app-spec.md) — границы первой версии, архитектура, модель данных, команды сервера, экраны, интеграция с Telegram, план поставки.
- [Книга ведущего](prototypes/magic-fair-v2.html) — основная история для 17 игроков, досье с секретами, действия по актам, связи и повороты; финал в переработке. [Источники и сборка](design/gm-book/README.md).
- [Дополнение до 30](prototypes/magic-fair-expansion.html) — 13 дополнительных ролей, сохранённые ветки и полная прежняя книга.
- [Архив страницы ревью 0.2](prototypes/magic-fair-v2-archive.html) — прежний планировщик состава и макеты.
- [Подробный HTML-проект](prototypes/magic-fair.html) — 17 персонажей с отыгрышем, ресурсы, квартира, мини-игры, макет приложения и инструменты ведущего.
- [Данные игры](design/game-data.json) — экспорт персонажей, фракций, реликвий, рецептов и комнат из HTML.
- [Рабочий Telegram Mini App](../apps/mini-app/README.md) — назначение папки и границы текущего прототипа.

HTML-файлы нужно открыть в браузере или через локальный сервер; просмотр исходника на GitHub не запускает страницу.

## Статус материалов

Импорт выполнен 23 октября 2026 года. Все три исходных HTML и оба документа сохранены без изменений в соответствующих папках. Исходные документы в Downloads также сохранены.

Временные скрипты сборки и снимки браузера из прежнего `/tmp` на момент импорта отсутствовали. HTML автономны и содержат стили, иллюстрации, данные и логику демонстрации; эти материалы не потеряны. `game-data.json` извлечён непосредственно из сохранённого HTML.
