# Ярмарка украденной магии

Хеллоуинская ролевая игра для 17 игроков и одного ведущего. Игроки встречаются в квартире, договариваются, торгуют и выполняют личные цели; собственный Telegram Mini App будет хранить роли и учитывать игровые действия.

Сейчас в репозитории собраны проект игры, визуальные HTML-прототипы и материалы прошлой ролевки. Рабочее приложение ещё не реализовано. Числа, цены и способности в проекте требуют игрового прогона.

## Структура

```text
apps/
  mini-app/              место для приложения
docs/
  design/                правила и экспорт данных персонажей
  prototypes/            все три существующих HTML-макета
  references/            исходные DOCX и XLSX прошлой игры
  requirements.md        ограничения и пожелания
  README.md              навигатор
```

Три HTML-файла в корне перенаправляют на соответствующие страницы в `docs/prototypes`, чтобы прежние локальные ссылки продолжали работать.

## Просмотр

HTML-макеты автономны: откройте `docs/prototypes/magic-fair.html` двойным щелчком. Устанавливать зависимости не нужно.

При желании можно открыть их через локальный HTTP-сервер из корня репозитория:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Адрес проекта: <http://127.0.0.1:8080/docs/prototypes/magic-fair.html>.

Действия в макете локальны, участники вымышлены, данные сбрасываются при обновлении страницы. Макет не подключён к Telegram и не подходит для проведения общей игры на нескольких телефонах.
