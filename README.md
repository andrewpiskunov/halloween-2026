# Ярмарка украденной магии

Хеллоуинская ролевая игра: основной сценарий на 17 игроков и одного ведущего; материалы для расширения до 30 сохранены отдельно. Игроки встречаются, договариваются, торгуют и решают судьбу сердца дракона Сарна. Рабочий Telegram Mini App хранит роли, сделки, способности, личные цели и решения ведущего.

## С чего начать

- [Книга ведущего — открыть HTML](docs/prototypes/magic-fair-v2.html): история на 17 игроков, отдельные досье, секреты, связи и сюжетные повороты. Только для ведущего.
- [Дополнение до 30](docs/prototypes/magic-fair-expansion.html): ещё 13 ролей и полная прежняя редакция для будущих доработок.
- [Навигатор по документации](docs/README.md).
- [Памятка проведения вечера](docs/design/gm-runbook.md).
- [Свободные заявки и вмешательства ведущего](docs/design/free-play.md).
- [Telegram Mini App](apps/mini-app/README.md).

## Просмотр книги

Откройте `index.html` или `docs/prototypes/magic-fair-v2.html` в браузере. Интернет и установка зависимостей для просмотра не нужны. Портреты, стили и навигация хранятся рядом со страницами; при переносе сохраняйте всю папку `docs/prototypes`.

Книга содержит все тайны. Она показывает стартовое распределение и возможности сюжета, а актуальные инвентари и решения живой сессии находятся в приложении. В каталоге работает поиск и фильтр по стороне, на отдельной странице можно распечатать досье персонажа.

## Структура

```text
apps/mini-app/                  рабочее приложение, сервер и проверки
docs/design/                   правила и исходные игровые данные
docs/design/gm-book/            редакторские материалы и снимок книги
docs/prototypes/               книга ведущего и архивы прототипов
docs/prototypes/characters/    30 отдельных страниц персонажей
docs/prototypes/assets/        локальные изображения, стили и скрипты
docs/references/               неизменённые DOCX/XLSX прошлой игры
scripts/                       воспроизводимая сборка и проверка книги
```

## Обновление книги

После установки зависимостей Mini App:

```sh
python3 scripts/build-gm-book.py
python3 scripts/check-gm-book.py
```

[Источники и правила обновления](docs/design/gm-book/README.md). Старая страница с планировщиком состава и демонстрацией интерфейсов сохранена в [архиве 0.2](docs/prototypes/magic-fair-v2-archive.html). Локальные симуляции старых прототипов не являются серверной реализацией игры.
