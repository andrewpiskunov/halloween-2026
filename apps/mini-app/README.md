# Telegram Mini App

Здесь будет код собственного приложения для «Ярмарки украденной магии». Сейчас сохранено место в структуре репозитория; рабочий клиент, сервер и интеграция с Telegram ещё не созданы, зависимости не установлены.

## Существующий пример

[Интерактивный HTML](../../docs/prototypes/magic-fair.html) показывает сценарий за алхимика Грету: роль и отыгрыш, инвентарь, подготовку способности, изготовление, сделку с подтверждением, вклады в ритуалы и переключение актов ведущим.

Это локальная демонстрация с вымышленными партнёрами. Состояние хранится только в памяти страницы, согласие партнёра имитируется кнопкой, а перезагрузка сбрасывает действия.

## Предполагаемые части приложения

- Для игрока: роль и подсказки по отыгрышу, личные цели, сумка, сделки, рецепты, способности, мини-игры, ритуалы и объявления.
- Для ведущего: распределение ролей, список присутствующих, адаптация стартового набора, запуск актов, публикация лотов, журнал действий и фиксация финала.
- Для общей игры: серверное состояние сессии, проверка прав, резервирование ресурсов, атомарные обмены и защита от повторного применения одной операции.

Это направления из текущего проекта. Их порядок и точный объём первой версии ещё предстоит определить.
