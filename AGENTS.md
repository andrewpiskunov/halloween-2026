# Работа с проектом

- Общаться с владельцем и писать документацию на русском языке.
- Сначала читать `docs/requirements.md` и `docs/design/README.md`: в них отделены пожелания владельца от предложенных правил.
- Сохранять весь проект в этом репозитории; место для Telegram Mini App — `apps/mini-app`.
- `docs/prototypes` содержит автономные визуальные прототипы. Их локальные симуляции не являются серверной реализацией игры.
- `docs/design/game-data.json` — снимок данных из HTML. При изменении данных в прототипе обновлять снимок либо явно документировать расхождение.
- Не изменять исходные DOCX/XLSX в `docs/references` при разработке игры.
- Поддерживать личные цели, обмены, уникальные способности и подсказки по отыгрышу всех персонажей. Не создавать критическую зависимость от присутствия одного гостя.
- Все коммиты создавать с автором и коммитером `Andrew Piskunov <45717261+andrewpiskunov@users.noreply.github.com>`. Не добавлять упоминания инструментов, автоматического авторства и строки `Co-authored-by`.
- Не сохранять токены Telegram, секреты, персональные списки гостей или реальные состояния игровых сессий в Git. Для примеров использовать вымышленные данные.
